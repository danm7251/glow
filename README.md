# Glow
A local audio player built using egui and eframe.

## Early Release Features (WIP)
- [x] Display local songs with title and artist
- [x] Play/Pause/Stop
- [x] Edit and save metadata
- [x] Drag and drop support
- [x] Volume Control
- [ ] Seek bar
- [ ] Filter songs by Artist
- [ ] Queuing
- [ ] Skip/Back
- [ ] Playlists

## Full Release Features
- [ ] Search
- [ ] Display art
- [ ] Theme customisation
- [ ] Persistent user settings
- [ ] Multi-format support
